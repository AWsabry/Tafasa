# Fonts Required

Please add the following font files to this directory:

## Arabic Font (FF Khallab)
- `FFKhallab.ttf` - Regular weight
- `FFKhallab-Bold.ttf` - Bold weight (700)

## English Font (Graphic School)
- `GraphicSchool.ttf` - Regular weight
- `GraphicSchool-Bold.ttf` - Bold weight (700)

## Instructions
1. Download or obtain the font files
2. Place them in this `assets/fonts/` directory
3. Make sure the filenames match exactly as listed above
4. Run `flutter pub get` to refresh assets
5. Restart your app

## Note
Until you add the actual font files, the app will use the system default fonts. The app may show warnings about missing fonts in the debug console, but it will still run.
